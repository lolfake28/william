Hobi Pet Store is an online platform I developed using Laravel, Vue, Tailwind CSS, and JavaScript. The website offers a user-friendly interface for managing pet products, with a focus on smooth and intuitive navigation. It features a responsive design that ensures seamless shopping experiences across devices, while leveraging modern technologies to provide a fast and efficient user interface.
